# Portfolio workspace

Make Journals the primary working surface. Explore menu-first navigation between
Journals and Dashboard without requiring a sidebar or horizontal navigation.
The product is cash-flow-first; double-entry details support advanced workflows.

## Portfolio protection scope

Distinguish an app-only password gate from encryption of the `.wfolio` file:
only encryption protects a copied file from being read outside Wishlez. Evaluate
SQLCipher with rusqlite for password-based database encryption, including
cross-platform builds, unlock prompts before database reads, safe migration of
existing plaintext portfolios, password changes, and backup protection. Do not
store or log plaintext passwords.
