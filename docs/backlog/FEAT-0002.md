# Journal editing and transaction actions

Keep common actions contextual, with native-menu alternatives.
Convert to Journal automatically classifies a transaction as income or expense
and balances it against the appropriate built-in account.
Reconcile Selected brings selected transactions into an editor to balance them
into journals; it is not merely marking statement entries cleared.
