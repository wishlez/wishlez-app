# Transaction imports

Import bank, credit-card, and eventually merchant transactions. Merchant detail
such as Amazon purchases can be reconciled with card activity rather than
counted as additional spending.

## Tasks

| Task | Status |

| Implement the first end-to-end import with useful error feedback | ○ |
| Define repeat-import and duplicate-detection behavior | ○ |
| Add a discoverable Import Transactions command | ○ |
| Support additional bank and card sources | ○ |
| Evaluate merchant-detail imports such as Amazon | ○ |
| Verify transfers and merchant detail do not inflate spending totals | ○ |

## Open decisions

- Available source formats, identifiers, currencies, and date conventions.
- How overlapping bank, card, and merchant records are represented.
- How much import preview and correction the first version requires.
