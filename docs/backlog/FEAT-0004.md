# Automated tagging

Tags are the main classification mechanism. Use model suggestions to reduce
manual work. An earlier iteration also used regex-based import/edit rules to
add selected tags; evaluate that approach here without assuming it already exists.

## Tasks

| Task | Status |
| --- | --- |
| Define suggestion inputs, output, and model integration | ○ |
| Provide quick acceptance, correction, and bulk tagging | ○ |
| Evaluate deterministic regex/criteria-based tagging rules | ○ |
| Define rule execution on import and edit | ○ |
| Define precedence between user choices, rules, and model suggestions | ○ |
| Explain automated suggestions without silently replacing deliberate choices | ○ |
| Decide whether and how corrections improve later suggestions | ○ |
| Verify repeat processing is predictable and avoids duplicate tag assignments | ○ |

## Open decisions

- Model choice and execution environment.
- Rule ordering, conflicts, and retroactive application.
- Feedback storage and which cases need review.
