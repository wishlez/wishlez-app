# Sequential reconciliation

Favor a predictable review sequence over repeatedly constructing selections.
Present proposed relationships across accounts, then allow acceptance and
advancement, adjustment, or skipping.

An earlier iteration showed amount matches between two accounts within about
a week and supported bulk selection. That is useful prior art, not a requirement
to recreate the same window.
