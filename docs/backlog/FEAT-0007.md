# Account and tag management

Keep occasional management out of the primary transaction workspace.
Accounts are virtual piggy banks rather than a requirement to learn accounting.

## Open decisions

- Dialog versus workspace/window for tag management.
- Whether repeated management commands focus an existing window.
- Rename, merge, archive, and delete semantics.
- How opening balances are entered and updated.
- Whether an account's type may change once journals reference it.

Duplicate account names are allowed; names are not required to be unique.
