# Feature backlog

Feature files contain their own task tables. This index summarizes features only.
Table statuses: ○ todo, ◐ in progress, ✓ done. YAML frontmatter keeps the text
values `todo`, `in-progress`, and `done`. Feature frontmatter is authoritative;
keep this table synchronized with it. Keep feature IDs and filenames stable after
completion.

These are potential tasks, not a commitment to implement every idea. Refine open
decisions before implementation. Mark tasks done only from verified work or user
confirmation; a feature is done when its agreed scope is complete.
